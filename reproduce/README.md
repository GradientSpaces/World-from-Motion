# Table 1 reproduction tools

Start with [REPRODUCTION.md](../REPRODUCTION.md) for the complete Ours (sample)
and Ours (distill) workflow, input setup, reference numbers and validation limits.

- `from_raw/`: verified downloads and independent reconstruction through evaluation.
- `sampling/`: direct-video sampling collection and previews.
- `table1/`: method-specific fitting/evaluation, aggregation and reference values.
- [SOURCE.json](SOURCE.json): imported source revision and hashes before adaptation.

The research backends and runtime snapshots retain their existing layout to
preserve import isolation and numerical behavior. Their licenses and provenance
are described in [third-party notices](../THIRD_PARTY_NOTICES.md). Generated
campaign assets and model weights are excluded from this source package.
